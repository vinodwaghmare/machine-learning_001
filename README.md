# machine-learning_001

Env
----
Recommended to use virtual env so the the packages remains isolated from local 
-- python -m env env (only create one time)
-- venv\Scripts\activate (activated only for session)

Packages 
--------
Packages version installed should be compatible with python version for local or virtual env

ikernel
--------
It's package which allows to run python code on juypter notebook
-- python -m ipykernel install --user --name Vinod --display-name "Python 3.13.3 (ipykernel)" (To install & register python env as a kernel for juypter notebook)
